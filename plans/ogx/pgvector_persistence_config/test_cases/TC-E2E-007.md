# TC-E2E-007: Declarative pgvector CR without id derives provider_id and still emits persistence

**Objective**:

A declarative pgvector provider with `id` omitted generates `provider_id: remote-pgvector`, the
derived `OGX_REMOTE_PGVECTOR_PASSWORD` reference, the `vector_index` map and the `persistence`
block. This case asserts emitted configuration only and never starts a pod, because the emitted
`vector_index` shape does not match the server's `PGVectorIndexConfig`, an acknowledged
out-of-scope follow-up.

**Preconditions**:

- All preconditions of TC-E2E-001
- Secret `pgvector-secret` (key `password`) exists in `ogx-pgvector-test` with the label
  `ogx.io/watch: "true"`

**Test Steps**:

1. Apply the `OGXServer` CR from Test Data
2. Wait 120s for `ConfigGenerated=true` on `ogxserver/ogxserver-derived-id`
3. Save the generated `remote::pgvector` entry as `generated-pgvector.yaml`
4. Diff it against the Expected Response saved as `expected-pgvector.yaml`, both passed through
   `yq -P 'sort_keys(..)'`

**Expected Results**:

- Step 3 output has `provider_id: remote-pgvector`,
  `password: ${env.OGX_REMOTE_PGVECTOR_PASSWORD}`, `distance_metric: COSINE`,
  `vector_index.hnsw` with `m: 16`, `ef_construction: 200`, `ef_search: 100`, and
  `persistence` with `backend: kv_default` and `namespace: vector_io::pgvector`
- Step 4 prints no differences (exit code 0)

**Test Data**:

The TC-E2E-001 CR with `metadata.name: ogxserver-derived-id` and the pgvector provider replaced
by the golden fixture shape, which omits `id`. This mirrors
`cmd/configgen/testdata/p1-pgvector-config/cr.yaml`.

```yaml
        pgvector:
        - host: pgvector.example.com
          port: 5432
          db: vectors
          user: pguser
          password:
            name: pgvector-secret
            key: password
          distanceMetric: COSINE
          vectorIndex:
            hnsw:
              m: 16
              efConstruction: 200
              efSearch: 100
```

**Expected Response**:

```yaml
# expected-pgvector.yaml — the pgvector entry the operator emits, matching
# cmd/configgen/testdata/p1-pgvector-config/want-config.yaml at the fix commit
provider_id: remote-pgvector
provider_type: remote::pgvector
config:
  host: pgvector.example.com
  port: 5432
  db: vectors
  user: pguser
  password: ${env.OGX_REMOTE_PGVECTOR_PASSWORD}
  distance_metric: COSINE
  vector_index:
    hnsw:
      m: 16
      ef_construction: 200
      ef_search: 100
  persistence:
    backend: kv_default
    namespace: vector_io::pgvector
```
